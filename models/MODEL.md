# Model Artifacts

This directory holds trained models and HLS-generated projects. All of it is
**gitignored** (large binaries), so a fresh clone starts empty. This file is the
one tracked exception, kept so you know what must be placed here.

## Required for the hls4ml pipeline

The conversion scripts in `hls4ml/` expect the trained DeepSets model at:

```
models/deepsets_d64_l3_ffn128/deepsets_clean.h5
```

This is the attention-free DeepSets variant (BitFFN + LayerNorm + residuals +
`GlobalAveragePooling1D`) that targets FPGA synthesis. Without it,
`hls4ml/hls_convert_v2.py` will fail at `tf.keras.models.load_model(...)`.

To regenerate it, train with `qkerasModel.py` / `train.py` (see the top-level
README) and save the cleaned Keras `.h5` to the path above.

## Generated by the pipeline (do not commit)

These are produced by running the conversion scripts and are intentionally
untracked:

- `models/hls4ml_deepsets_v2/`        — io_parallel project (`hls_convert_v2.py`)
- `models/hls4ml_deepsets_iostream/`  — io_stream project (`hls_convert_iostream.py`)
- `models/transformer_*`              — transformer / KD run artifacts

## Physics test data

`hls_convert_v2.py` / `hls_convert_iostream.py` also reference physics test data
via a `DATA_DIR` near the bottom of each script. That path is environment
specific (e.g. `/home/users/kayamaguchi/BNJetTag/dataForgeScripts`); edit it to
point at your local `testingDataSigpt30.h5` / `testingDataQCDpt30.h5`. If the
files are absent the scripts still run the noise-input C-sim and just skip the
physics comparison.
